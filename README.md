Projeto Prático – CRUD de Usuários (Java e Spring Boot)
Desenvolvimento de um CRUD completo para cadastro de usuários, utilizando Java e Spring Boot. 
Implementação de operações de criação, leitura, atualização e exclusão de dados por meio de APIs
REST, com persistência utilizando Spring Data JPA e banco de dados H2. Organização do projeto com 
Maven, uso de Lombok para redução de código boilerplate e boas práticas de estruturação backend. 
Versionamento do código realizado com Git e GitHub.
**`Tecnologias utilizadas:`** Java 23 (JDK 23), Spring Boot, Spring Data JPA, H2 Database, Maven e Lombok.
